# Product Overview

This is a banner generation web application that creates customized advertising banners using AI image processing. The application allows users to upload images (background, logo, product) and input text content to generate professional marketing banners in various standard sizes.

## Key Features

- **Multi-format banner generation**: Supports standard ad sizes (300x250, 300x600, 640x1280, 640x320, 660x300, 980x250)
- **AI-powered background processing**: Uses OpenAI's image editing API to enhance and adapt backgrounds
- **Dynamic text overlay**: Supports company names, product names, subtexts, CTAs, discounts, and contact info
- **Image upload handling**: Processes background images, logos, and product photos
- **Web-based interface**: Flask application with HTML forms for user input

## Target Use Case

Marketing teams and businesses need to quickly generate professional advertising banners for digital campaigns without requiring design expertise or expensive software.
